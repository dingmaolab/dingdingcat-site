前两课施工，我一直在说"勾一格 commit 一格"。今天来回答那个躲不掉的问题：**勾，凭什么算完成？**

这一课不讲理论，就地取证——验收的对象，就是这两天刚盖完的这个站。下面每一条，都是今天下午在这个站上真跑出来的输出，包括它当场给我抓出的那个 bug。

## 本课目标

- 分清两种验收：机器的（写成脚本，能重复）和人的（靠判断力，只能抽样）
- 六个立刻能抄的验收动作，每个附今天的真实输出
- 理解一件反直觉的事：AI 的校对报告不可完全复现，这不可耻，是它的性质

## 概念卡

- **验收条款**：清单里每条任务后面那句"怎样才算做完"。它的合格标准只有一条：能当场执行、当场判真假。
- **死链扫描**：把所有页面里的链接抠出来，逐个验证目标文件存不存在。十五行脚本的事，抓到的是"用户一点就 404"级别的用户体验事故。
- **负向测试**：故意喂坏数据，验证系统会不会装死。报错停下是及格，静默吞掉是不及格。

## 机器侧：六技，六份原始输出

**一，死链扫描。** 脚本一跑，屏上蹦出来：`106 本地链接 / 断链 50`。

五成断链？点开看，全是同一族：文章页生成在 `a/` 子目录里，可页面导航还写着 `href="index.html"`——从任何一篇文章里点"主页"，404。这 bug 是我写模板那天埋的，当时脑子里只有根目录，没想过"子目录里的页面往哪跳"。

修法两行：page() 加一个 base 参数，a/ 页面全带 `../`。改完复扫：`106 / 0`。单独一个 commit，消息里把"首跑 50 条、文章内点主页即 404"写明白——**修 bug 的 commit 是写给三个月后的自己看的**。

**二，负向测试。** 我往 articles 里塞了个 frontmatter 写着 `kind: xxx` 的坏文件，跑构建。它没装死：`未知 kind: 'xxx'（z-test-坏kind.md）。允许值：course/post/gallery。拒绝静默。`——退出码 1。删掉坏文件，重建全绿。

**三，组合状态。** 单点测试都绿不等于组合不炸。脚本点开"发刊词"chip、同时往搜索框打"NAS"——空态正常出现；点"清空筛选"，可见行复位到 1。两个功能打架的高发区，就在这类"又点又搜"的组合里。

**四，刁钻输入。** 搜索框灌 `'; DROP TABLE--`——页面活着，空态正常。它当然没有数据库给我 DROP，但这类串专炸"把输入直接拼进逻辑"的代码。炸不炸，一试就知道；试的成本，十五秒。

**五，JS 错误监听。** 连着打开四个页面加一轮搜索操作，浏览器控制台里的 pageerror 计数：0。

**六，三断点截图。** 390、768、1280 各截一轮图目检。CSS 里写了媒体查询，不等于媒体查询里每一条都对——截图不会说谎，代码会。

## 人侧：内容要人来验，但人得防着 AI 的"印象分"

机器管结构和交互，管不了内容对不对。内容这一侧，我今天动了两件武器。

**零背景校对。** 派一个从未经手这篇文章的全新 AI，只给它文件和六个问题（错别字/逻辑断层/术语门槛/事实强度/标题兑现/一句话主旨）。今天上午它交回的报告，最有意思的不是它挑了什么，是**我驳回了什么**：它说 frontmatter 里 `number: 1` 和文件名 002 对不上，疑似 bug——这是假阳性。number 是**系列内**编号（这篇是"讲清"系列第 1 篇），文件名是站内全局流水号，两套编号各司其职。

AI 的校对报告，本身也要被校对。采纳它判得准的（引号笔误、一个逻辑前提缺失），驳回它想当然的——这一来一回，才是"AI 当第一个读者"的完整姿势：**它负责看见，你负责裁决。**

**"空"不等于"坏"。** 还有一笔旧账：更早那次调 API 要摘要，返回是空的。它没报错，HTTP 一切正常。真相是 max_tokens 只给了 200，而那是个思考模型——200 额度全花在"想"上，没剩给"答"。空，是一个你没预设过的合理状态。验收遇到"没东西"，先问为什么空，别急着判死刑。

## 第七节：验收课自己交的作业

写这节课的素材账时，我引用了上午那份校对报告，写的是"已存档"。落笔后顺手 grep 了一下——**没这个文件**。报告只存在于当时那轮会话里，我把它在对话记录里看过，当成了"存过"。

当场重跑：又派一个零背景 AI 读同一篇，这次落盘为文件。然后做了一件今天最值得教的事——把上下午两份同题报告逐条对了一遍。

【比对结论落此处：两次报告的相同项与差异项——见本目录 校对002-第二次.md 对照上午报告。】

两份报告摆在一起，比对表落在本目录 `校对002-第二次.md` 末尾，三行就够说明问题：

- **两次都命中的**：结尾那个缺失的因果前提（"不翻墙"那句话推不出来）、"可以装 DeepSeek"这句承重断言没交代来路。交集，闭眼采纳。
- **第二次反而漏掉的**：一处直引号笔误。第一次用精确匹配抓到了，第二次重跑同一篇，报告写着"未发现标点错误"。**这个笔误是真实存在的**——同一条码，AI 一次看得见一次看不见。
- **第二次新挖出来的**："不翻墙用国产模型"这个短语修饰对象挂错了（该说的是外壳不翻墙，现在读着像国产模型要翻墙），第一次居然没人指出来。

结论不伤人反而清醒：**同一篇文章、同样的指令、同样没背景的两个 AI，报告不是复印机。** 内容验收的本性是抽样检验，不是流水线检测。抽样要可信，靠三样：取交集当硬证据、并集当线索池、裁决权留在人。高风险内容，抽两次。

素材账说谎被抓这件事本身，也是这课的一部分。写进清单时那句"报告已存档"，和网站里那句"已发布 7 课"，是同一种病：**把"我知道"当成了"有凭证"。** 机器侧的六技为什么硬？因为它们每一条都先有输出再有结论。

## 跟做步骤

1. 给你的站写一个十五行的死链脚本（正则抠 href，逐个查存在性）——今天先跑，今天就有 bug 修
2. 给生成器做一次负向测试：塞一份故意坏的数据，要求它报错停下而不是跳过去
3. 把清单里每条验收念一遍：念完你能当场执行出真或假的才算过，执行不了的改写到能执行为止
4. 内容侧：发一篇出去之前，开一个零背景 AI 问六件事；报告落盘，逐条采纳或驳回，驳回的写理由
5. 每次重要发布前，390/768/1280 三张截图扫一眼，比读 CSS 快

## 及格标准

你今天抓到过一个东西——bug、假阳性、或者自己素材账里的一句谎，三样里任意一样，并且它最后变成了清单里的新条款或仓库里的新文件。验收这门手艺，入门标志不是全绿，是**第一次被绿里的假象骗到之后，加了道闸**。

## 卡住了

- **写不出脚本**：把验收动作一步步说给 AI，让它写，你负责读它的逻辑对不对。这本来就是这门课的主方法。
- **校对报告全是噪音**：多半是问题给得太泛。"帮我看看"会收获礼貌；六个具体问题才收获证据。
- **每次 AI 说法不一样就慌**：不用统一它们，用交集。两次都命中的，几乎一定真；只出现一次的，去原文找它有没有依据。
