这是「Vibe Coding 上手课」的第 1 课，整个系列就这一节是厚课。

它要干三件事：带你认全这条链上的几个词，把 Claude Code 装进你的电脑，接上一个国产模型，然后说出头一句话。

学完你手里会有一个能跑的环境，和一句 AI 给你的真实回答。后面所有的课，都从这个环境里长出来。

整个系列怎么排的，先交个底：跟着一个真实项目的研发流程走。备工具，存代码，拷问需求，定方案，拆任务，开发，测试，上线。十五课，一课一步。你最后手里攥着的不是十几个知识点，是完整干过一个项目的证据。

## 本课目标

- 说清 model、harness、skill、MCP、agent 各是什么，谁管谁
- 在自己电脑上装好 Claude Code，并验证成功
- 接上 DeepSeek，跑出开口一句对话

## 概念卡

先认几个词。这一课只要求你认得，不要求你会用。后面会一个个用到。

- **模型（model）**：真正"思考"的大脑，比如 DeepSeek、通义千问、GLM。负责理解和生成。
- **harness**：套在模型外面的工程层，给它配上读文件、跑命令的手脚，加上那个循环。这不是什么圈内黑话，是 Anthropic 的官方用词——他们的研究文章里直接写：Claude Code 是一个出色的 harness，Agent SDK 是一个通用 agent harness（链接在文末深入读）。
- **agent**：能自己多步完成任务的 AI。官方定义出自 Anthropic 那篇被引最多的术语文章《Building effective agents》：模型自己主导流程和工具使用，自己掌控怎么把事做完——和"按预定义代码路径跑的 workflow"相对。关键在那个循环：观察、思考、动手、再看结果，反复直到做完。至于"agent = 模型 + harness"这个公式，是业界的流行简化、不是官方原话，但好记——用它别漏了"自主"这个灵魂。
- **skill**：打包好的一套做事指令，写在一个叫 SKILL.md 的文件里，让 AI 遇到某类任务按固定流程做。后面你会自己做一个。
- **MCP**：全称 Model Context Protocol，模型上下文协议。模型本身关在盒子里，碰不到你的文件、数据库和外部服务。MCP 给 AI 应用配了一个标准接口，让它能安全地连上这些外部系统。官方打了个比方：像 USB-C 口——统一标准，各种设备即插即用，不用每样单独接线。它是开放协议，不只一家在用，Claude、ChatGPT、VS Code、Cursor 都支持。这一课先认得它，后面你会亲手做一个。
- **插件（plugin）**：官方的定义很朴素——一个装组件的目录，里面的 skill、agent、MCP 服务等东西，整体安装、整体加载，一般从插件市场获取。它不是模型，是挂在 harness 上的"能力扩展包"。

记住这个关系：模型给大脑，harness 给手脚和循环，这两样合起来就是一个能转的 agent。skill 给规矩、MCP 给接口、插件把这几样打包，都是往上加的本事，不是必需零件。

### 这五个词，是一条因果链

词条是查字典的讲法。我再给你一条来龙去脉——它们不是五个被同时发明出来的产品，每一个都是为了让上一个能干活。

模型学会了思考。可它关在盒子里，看不见你的文件，也跑不了命令。

于是有了 harness，给它配上手脚，让它读得到、改得动。

但一件大事没法一口气干完，得做完一步看看结果再走下一步。

于是有了 agent 那个循环：观察、思考、动手，直到做完。

循环能跑了，同类的事每次都要重新交代一遍规矩，烦。

于是有了 skill，规矩写进一个文件，遇到这活就按流程走。

手脚有了，可外面的世界还有一片山：数据库、浏览器、云盘。每家单独接一根专用线，接不过来。

于是有了 MCP，统一成 USB-C 那样的口，什么都即插即用。

最后想把这些本事整体送给别人，就打包成插件。

一条链记住就行：思考，手脚，自主循环，规矩，接口，打包。往后这门课里出现的任何新名词，你都能往这条线上找它的位置。

## 实跑记录

### 一、为什么是现在

你可能听过"AI 会写代码"好几年了，但一直觉得离自己很远。

变化发生在最近。模型写代码的能力过了一个坎，从"补全一行"变成"听懂一段需求，自己改好几个文件"。拿国产模型来试，成本也低，个人完全试得起——后面我会给你看真实的账单。

这两件事凑在一起，才让"用自然语言指挥 AI 干活"从演示变成日常。2025 年初，Karpathy 给这种方式起了个名字，叫 vibe coding。

我不打算给你背一段 AI 编年史。你只需要知道：现在上车，门槛比过去低得多。

### 二、先分清两族东西

新手最容易混的，是把"模型"和"工具"当成一回事。

其实是两族。

一族是模型：DeepSeek、通义千问、GLM、Kimi。它们是大脑，按 token 收费。

另一族是 harness 和 IDE：Claude Code、Codex 是命令行 harness，Trae、CodeBuddy 是带界面的编辑器。它们是手脚，本身不"思考"，而是去调用某个模型。

关键的一句：**harness 和模型是可以分开配的**。Claude Code 这个外壳，里面可以装 DeepSeek 的大脑。

这正是我们这套课的路线——外壳只用 Claude Code 一个，大脑用国产模型。不翻墙，便宜。

为什么只选一个外壳？因为新手最怕选择题。你不需要在五个工具里纠结，跟着一个走通，比每个都摸一遍强。

### 三、装好 Claude Code

打开你电脑的终端。Windows 上就是 PowerShell。

官方现在推荐原生安装。在 PowerShell 里粘这一行，回车：

```powershell
irm https://claude.ai/install.ps1 | iex
```

如果你更习惯 npm，也可以用它装（需要 Node.js 22 以上）：

```powershell
npm install -g @anthropic-ai/claude-code@latest
```

两条路装的是同一个东西，选一条就行。Windows 上建议先装好 Git for Windows，Claude Code 的某些工具会用到它。

装完别急着下一步，先验证。跑：

```powershell
claude doctor
```

它会打印一份只读体检报告。翻到最后，看到这一句就成了：

```
No installation issues found.
```

我本机跑出来的是 2.1.325 版，npm 方式装的，体检通过。你的版本号可能不同，没关系，看到"没有安装问题"就够了。

### 四、接上 DeepSeek

外壳有了，现在给它装大脑。

第一步，去拿一把钥匙。打开 platform.deepseek.com，登录，点左侧菜单的「API keys」，再点「创建 API key」。

这里有个坑，必须先说：**key 只在创建那一刻完整显示一次**。页面一关，就再也看不到了，平台只存哈希，不存明文。

所以顺序别反：先准备好一个保存的地方（密码管理器，或本机一个不会进 git 的私密文件），再点创建，弹出来立刻复制存好，确认存住了再关页面。

我截了一张 API keys 页面：

![DeepSeek API keys 页面，旧 key 已打码](deepseek-api-keys.png)

列表里的旧 key 都是打码的——这就是"创建后看不到全文"的样子。

第二步，告诉 Claude Code 去哪找 DeepSeek。编辑你用户目录下的 `.claude\settings.json`，完整路径是 `C:\Users\你的用户名\.claude\settings.json`，在 `env` 字段里写：

```json
{
  "env": {
    "ANTHROPIC_BASE_URL": "https://api.deepseek.com/anthropic",
    "ANTHROPIC_AUTH_TOKEN": "你刚存好的那把 key",
    "ANTHROPIC_MODEL": "deepseek-flash"
  }
}
```

三个地方注意。base_url 末尾的 `/anthropic` 不能省，那是 DeepSeek 官方的兼容端点。key 填你自己那把，别抄别人的。模型名用 deepseek-flash 就够日常用，想要更强可以换 deepseek-v4-pro。

顺便说句实话：DeepSeek 的 API 不免费，但极便宜，几块钱能用很久。它的网页聊天免费，API 收费，别混了。想要真零成本，还有另一条路：阿里云有个叫百炼的大模型平台，通义千问这些模型就在上面跑，它给新用户每个模型一百万 token 的免费额度。课里后面会提。

### 五、开口一句

配置存好，重开一个终端，进到任意一个空文件夹，跑：

```powershell
claude
```

进去之后，问它一句：

> 你好，请用一句话介绍你自己，并告诉我你底层是什么模型。

我跑出来的回答，有意思的地方不在内容，在它自己把这一课的核心讲清楚了。它说：我是运行在 Claude Code 这个代理框架里的助手，环境声明我由 deepseek-flash 驱动，框架是 Anthropic 的，模型是 DeepSeek 的。

读到这句你应该笑了。**harness 和模型是两回事**——这个我前面讲了一遍的概念，模型自己又给你演示了一遍。

外壳是 Claude Code，大脑是 DeepSeek。你刚刚亲手把它们接在了一起。

这就是 vibe coding 的起点：一个听你说话的环境，加一个能思考的模型。

## 跟做步骤

把上面的实跑浓缩成五步，照着做：

1. PowerShell 跑 `irm https://claude.ai/install.ps1 | iex`（或 npm 那条），装 Claude Code
2. 跑 `claude doctor`，看到 "No installation issues found." 即装好
3. platform.deepseek.com → API keys → 创建 API key，**立刻复制存到私密文件**
4. 编辑 `C:\Users\你的用户名\.claude\settings.json` 的 env，填 base_url（带 /anthropic）、你的 key、模型名
5. 重开终端跑 `claude`，问它"你是什么模型"，看到它自报 DeepSeek 即接通

## 及格标准

打开终端跑 `claude`，问它底层是什么模型，它回答里出现 DeepSeek（或你配的那个国产模型），就算及格。

## 卡住了

- **install 报网络/权限错**：多半是网络或执行策略。换 npm 那条路试试，或查官方安装文档的排查节。
- **提示 unrecognized_model**：Claude Code 不认识非 Claude 的模型名会打印这行警告。它不是错误，照样能用，别慌。
- **key 填了还是连不上**：先查 base_url 末尾有没有 `/anthropic`，再查 key 是不是创建时存的那把完整明文（不是打码的）。key 丢了只能重建。

## 轮到你了

如果你跟着装好了，不妨现在就问它一句，看它是不是真接上了 DeepSeek。它答出来，这一课你就拿到了。

想再玩玩的，把模型名换成 deepseek-v4-pro 再问一次，对比两个模型的回答有什么不同。

下节课先不急着写代码。工作台得先搭起来——装个 IDE，让 AI 改文件的时候，你能在旁边看着它动了哪几行。
