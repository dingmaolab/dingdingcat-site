这是「Vibe Coding 上手课」的第 1 课，整个系列就这一节是厚课。它要干三件事：带你认全这条链上的几个词，把 Claude Code 装进你的电脑，接上一个国产模型，然后说出头一句话。学完你手里会有一个能跑的环境，和一句 AI 给你的真实回答——后面所有的课，都从这个环境里长出来。

整个系列怎么排的，先交个底：跟着一个真实项目的研发流程走。备工具，存代码，拷问需求，定方案，拆任务，开发，测试，上线。十五课，一课一步。你最后手里攥着的不是十几个知识点，是完整干过一个项目的证据。

本文顺序：先概念卡认词（只要求认得，不要求会用）；① 为什么是现在上车；② 分清两族东西；③ 装 Claude Code；④ 接 DeepSeek；⑤ 说出头一句话。②到⑤每步都告诉你"应看到什么"，对着检查就行。

## 本课目标

- 说清 model、harness、skill、MCP、agent 各是什么，谁管谁
- 在自己电脑上装好 Claude Code，并验证成功
- 接上 DeepSeek，跑出开口一句对话

## 概念卡

先认几个词。这一课只要求你认得，不要求你会用。后面会一个个用到。

- **模型（model）**：真正"思考"的大脑，比如 DeepSeek、通义千问、GLM。负责理解和生成。
- **harness**：套在模型外面的工程层，给它配上读文件、跑命令的手脚，加上那个循环。这不是什么圈内黑话，是 Anthropic 的官方用词——他们的研究文章里直接写：Claude Code 是一个出色的 harness，Agent SDK 是一个通用 agent harness（链接在文末深入读）。
- **agent**：能自己多步完成任务的 AI。官方定义出自 Anthropic 那篇被引最多的术语文章《Building effective agents》：模型自己主导流程和工具使用，自己掌控怎么把事做完——和"按预定义代码路径跑的 workflow"相对。关键在那个循环：观察、思考、动手、再看结果，反复直到做完。至于"agent = 模型 + harness"这个公式，是业界的流行简化、不是官方原话，但好记——用它别漏了"自主"这个灵魂。
- **skill**：打包好的一套做事指令，写在一个叫 SKILL.md 的文件里，让 AI 遇到某类任务按固定流程做。这一季你会在第 5 课真用上一个别人造好的。
- **MCP**：全称 Model Context Protocol，模型上下文协议。模型本身关在盒子里，碰不到你的文件、数据库和外部服务。MCP 给 AI 应用配了一个标准接口，让它能安全地连上这些外部系统。官方打了个比方：像 USB-C 口——统一标准，各种设备即插即用，不用每样单独接线。它是开放协议，不只一家在用，Claude、ChatGPT、VS Code、Cursor 都支持。
- **插件（plugin）**：官方的定义很朴素——一个装组件的目录，里面的 skill、agent、MCP 服务等东西，整体安装、整体加载，一般从插件市场获取。它不是模型，是挂在 harness 上的"能力扩展包"。

记住这个关系：模型给大脑，harness 给手脚和循环，这两样合起来就是一个能转的 agent。skill 给规矩、MCP 给接口、插件把这几样打包，都是往上加的本事，不是必需零件。

## ① 为什么是现在

你可能听过"AI 会写代码"好几年了，但一直觉得离自己很远。变化发生在最近：模型写代码的能力过了一个坎，从"补全一行"变成"听懂一段需求，自己改好几个文件"；拿国产模型来试，成本也低，个人完全试得起——后面我会给你看真实的账单。

这两件事凑在一起，才让"用自然语言指挥 AI 干活"从演示变成日常。2025 年初，Karpathy 给这种方式起了个名字，叫 vibe coding。我不打算给你背一段 AI 编年史。你只需要知道：现在上车，门槛比过去低得多。

## ② 先分清两族东西

新手最容易混的，是把"模型"和"工具"当成一回事。其实是两族。

一族是模型：DeepSeek、通义千问、GLM、Kimi。它们是大脑，按 token（喂进去和吐出来的字数单位）收费。

另一族是 harness 和 IDE：Claude Code、Codex 是命令行 harness，Trae、CodeBuddy 是带界面的编辑器。它们是手脚，本身不"思考"，而是去调用某个模型。

关键的一句：**harness 和模型是可以分开配的。** Claude Code 这个外壳，里面可以装 DeepSeek 的大脑。这正是我们这套课的路线——外壳只用 Claude Code 一个，大脑用国产模型。不翻墙，便宜。为什么只选一个外壳？因为新手最怕选择题：跟着一个走通，比五个工具各摸一遍强。

## ③ 装 Claude Code

打开你电脑的终端（Windows 上就是 PowerShell）。两条安装路线，装的是同一个东西，选一条就行：

| 路线 | 命令 | 应看到 |
|---|---|---|
| 官方原生（推荐） | Windows：`irm https://claude.ai/install.ps1 \| iex` | 下载进度跑完，无报错 |
| 官方原生 | Mac：`curl -fsSL https://claude.ai/install.sh \| bash`（终端 App 里粘） | 同上 |
| npm 通用（需 Node.js 22+） | `npm install -g @anthropic-ai/claude-code@latest` | 末尾一行 added N packages |

Windows 读者建议先装好 Git for Windows，Claude Code 的某些工具会用到它。丑话说在前面：**作者的机器是 Windows，Mac 那行按官方安装文档原样搬运（见文末链接），我本机没有跑过**——Mac 读者跑出问题，带着现象回来，我们就把它变成实测。

装完先验证，跑 `claude doctor`——它打印一份只读体检报告，翻到最后：

```
No installation issues found.
```

我本机跑出来的是 2.1.325 版（npm 方式装的），体检通过。你的版本号可能不同，没关系，看到"没有安装问题"就够了。

## ④ 接上 DeepSeek

外壳有了，给它装大脑。

| 步骤 | 操作 | 应看到 |
|---|---|---|
| 拿钥匙 | platform.deepseek.com 登录 → 左侧「API keys」→ 创建 API key | 一串以 sk- 开头的完整密钥，**只显示这一次** |
| 存钥匙 | 先备好保存的地方（密码管理器，或本机一个不进 git 的私密文件），复制，确认存住了再关页面 | 打开你存的地方能看到全文；网页上列表里的旧 key 全是打码的 |
| 配地址 | 编辑 `C:\Users\你的用户名\.claude\settings.json`（Mac 是 `~/.claude/settings.json`），在 `env` 字段里填下面三行 | 保存无报错 |

这里有个坑，必须先说：**key 只在创建那一刻完整显示一次**，平台只存哈希不存明文，页面一关就再也看不到。所以顺序别反：先准备好存的地方，再点创建。

```json
{
  "env": {
    "ANTHROPIC_BASE_URL": "https://api.deepseek.com/anthropic",
    "ANTHROPIC_AUTH_TOKEN": "你刚存好的那把 key",
    "ANTHROPIC_MODEL": "deepseek-flash"
  }
}
```

三个地方注意：base_url 末尾的 `/anthropic` 不能省，那是 DeepSeek 官方的兼容端点；key 填你自己那把，别抄别人的；模型名用 deepseek-flash 就够日常用，想要更强可以换 deepseek-v4-pro。

我截了一张 API keys 页面：

![DeepSeek API keys 页面，旧 key 已打码](deepseek-api-keys.png)

顺便说句实话：DeepSeek 的网页聊天免费，API 收费，别混了——API 极便宜，几块钱能用很久。想要真零成本，还有另一条路：阿里云百炼平台给新用户每个模型一百万 token 的免费额度，课里后面会提。

## ⑤ 说出头一句话

配置存好，重开一个终端，进到任意一个空文件夹，跑 `claude`。进去之后，问它一句：

> 你好，请用一句话介绍你自己，并告诉我你底层是什么模型。

我跑出来的回答，有意思的地方不在内容，在它自己把这一课的核心讲清楚了。它说：我是运行在 Claude Code 这个代理框架里的助手，环境声明我由 deepseek-flash 驱动，框架是 Anthropic 的，模型是 DeepSeek 的。

读到这句你应该笑了。**harness 和模型是两回事**——我前面讲了一遍的概念，模型自己又给你演示了一遍。外壳是 Claude Code，大脑是 DeepSeek，你刚刚亲手把它们接在了一起。这就是 vibe coding 的起点：一个听你说话的环境，加一个能思考的模型。

## 跟做步骤

1. 按 ③ 的表选一条路线装，`claude doctor` 看到 "No installation issues found." 再往下
2. 按 ④ 的表拿 key、存 key、配 settings.json 的 env 三行
3. 重开终端跑 `claude`，问它"你是什么模型"
4. 它自报 DeepSeek（或你配的那个国产模型），这一课就拿到了
5. 想再玩玩的，把模型名换成 deepseek-v4-pro 再问一次，对比两个模型的回答有什么不同

## 及格标准

打开终端跑 `claude`，问它底层是什么模型，它回答里出现 DeepSeek（或你配的那个国产模型），就算及格。

## 卡住了

- **install 报网络/权限错**：多半是网络或执行策略。换 npm 那条路试试，或查官方安装文档的排查节
- **提示 unrecognized_model**：Claude Code 不认识非 Claude 的模型名会打印这行警告。它不是错误，照样能用，别慌
- **key 填了还是连不上**：先查 base_url 末尾有没有 `/anthropic`，再查 key 是不是创建时存的那把完整明文（不是打码的）。key 丢了只能重建
- **Mac 装完敲 `claude` 说找不到命令**：官方 issue 区挂着的老坑——Homebrew 系 Node 用 npm 全局装容易把 PATH 走丢。最省事的解法不是修 PATH，是改用 ③ 表里那行 curl 原生安装；实在要用 npm，装完重开终端窗口再试
