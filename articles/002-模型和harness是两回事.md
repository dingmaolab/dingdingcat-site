新手最容易混的，是把模型和工具当成一回事。

模型是大脑，比如 DeepSeek、通义千问。它负责思考。

harness 是套在大脑外面的工作环境，比如 Claude Code。它给模型配上读文件、跑命令的手脚。

关键的一句：这两样可以分开配。Claude Code 这个外壳，里面可以装 DeepSeek 的大脑。

想明白这个，你就懂了为什么能"不翻墙用国产模型"——外壳不变，换个大脑而已。
