第1课，AI 有了手脚，能思考，能干活。但干活的地方是一个文字窗口。你让它改个文件，它回你一句"改好了"。

改没改，改在哪，有没有顺手多改，你一概看不见。

这不是 AI 的问题，是你没在机房。这一课把机房装成有监控的样子——它干活的时候，你看得见。

## 本课目标

- 装上 VS Code 和它的官方 Claude Code 扩展
- 分清图形面板和终端两种用法，知道它们是同一个引擎
- 做到新手最重要的一件事：让 AI 改一下文件，你打开 diff 亲眼看完

## 概念卡

这一课只有三个词，每个都当场要用。

- **IDE**：Integrated Development Environment，集成开发环境。名字唬人，东西不唬人——一个加强版文本编辑器，能开整个文件夹、看文件树、比对改动、还能内置终端。我们只用一种：VS Code，微软出的，免费，用的人最多。
- **扩展**：给 IDE 加的插件。装上 Claude Code 扩展，VS Code 里就多出一个专门的聊天面板，不用离开编辑器指挥 AI。
- **diff**：文件改动前后的对照视图。删了哪行、加了哪行，并排列给你看。这是你以后每次验收的核心工具，今天先见一面。

## 装配过程

### 第一步，把驾驶舱装上

电脑里没有 VS Code 的，浏览器打开 code.visualstudio.com，Download 按钮点下去，装的时候一路下一步。

已经装了的，确认版本不低于 1.94——那是官方扩展要求的底线。帮助菜单里点"关于"就能看到，或者终端里跑 `code --version`。我本机是 1.121.0，达标。

### 第二步，装扩展。这里我先替你把一堵小墙撞上

图形做法是在 VS Code 左侧点扩展图标，搜 Claude Code，点 Install。终端做法更短，PowerShell 里跑：

```powershell
code --install-extension anthropic.claude-code
```

我一开始敲的是 `anthropic.claude`，少了后面那截。报回来一行：

```
Extension 'anthropic.claude' not found.
```

扩展 ID 是"发布者.名字"的格式，差一个字符都不认。所以以后遇到 not found，别急着怀疑"这东西不存在吧"，先查 ID。

装对了的输长这样（版本号可能比我的新）：

```
Extension 'anthropic.claude-code' v2.1.330 was successfully installed.
```

想验一下，跑 `code --list-extensions`，列表里躺着这行就成了。

### 第三步，开文件夹，开面板

这一步是 IDE 和普通记事本分水岭第一次显形：**你打开的不是一个文件，是一个文件夹。**

File 菜单，Open Folder，选你的项目目录。还没有项目的，新建一个空文件夹就行，以后这门课都会在里面干活。

然后看侧边栏。这个扩展官方介绍的说法是，让你在 IDE 里用 Claude Code 而不用离开它，它给 VS Code 加了三个面板：主会话、副面板、会话列表。点开 Claude 入口，图形界面里就能开新会话，跟我平时用的命令行是同一个小脑瓜。

更喜欢终端的话，Ctrl+`（数字1左边那个键）打开 VS Code 内置终端，直接敲 `claude`。官方甚至提供一个叫 Claude Code: Use Terminal 的设置项，让你在图形和终端之间二选一。两种形态，一个引擎，穿没穿外套的区别。

### 第四步，本课的正主：看 diff

对 AI 说一句小事，比如：

> 在 hello.txt 里写三行自我介绍。

它干完，先别急着双击文件看内容。点左侧栏的源代码管理图标（分支形状那个），你的新文件就挂在那里。点开它，出现的就是 diff：左边一片空，右边三行绿，全是新增。

再让它改同一个文件："把第三行换成两句。"再开一次 diff，这回有绿有加，删的加的并排给你看。

把这个画面记住。以后所有课里的验收，"看、验、驳回"里的看，落点都是这一屏。官方 README 里写着它能"在你的编辑器窗口里直接提议改动"、"接受前先审它的计划"——话是它说的，账要你自己看。

AI 改文件不稀奇。稀奇的是你看得清它改在哪、有没有多手。这一眼，就是你和"盲信 AI"的人之间头一道分水岭。

## 跟做步骤

1. 装 VS Code，或确认版本 ≥ 1.94
2. `code --install-extension anthropic.claude-code`，用 `code --list-extensions` 验证
3. File → Open Folder 打开你的项目文件夹
4. 侧边栏点开 Claude 面板，或 Ctrl+` 开内置终端跑 `claude`
5. 让它建一个文件、再改同一个文件，两次都打开 diff 看完

## 及格标准

你亲眼看过两次 diff 画面——一次新建，一次修改——并且知道以后任何改动，去哪个图标下面找。不要求看懂代码，只要求看过。

## 卡住了

- **Extension not found**：ID 敲错了。正主是 `anthropic.claude-code`，我撞过这堵墙。
- **扩展装不上、搜索空白**：公司电脑配了代理的常见症状。正常渠道不行再来找我，这条我还没替你真跑过，先不乱开药方。
- **侧边栏找不到 Claude 图标**：先彻底退出 VS Code 重开一次。再看是不是没开文件夹——没打开项目，面板再在也没地方干活。
- **命令行不认 `code`**：重装 VS Code 时勾上"添加到 PATH"那个选项；或者先用图形界面，这条命令不是命根。

## 轮到你了

给 AI 提一个你"想看看它怎么下手"的要求。比如：把 hello.txt 拆成两个文件。看它干完，打开 diff，数一数它到底动了几个文件，跟你想要的是不是一回事。

下节课讲一件更重的事：它改的东西你要是反悔了，怎么退回去。diff 让你看清"改了什么"，git 让你能回到"没改之前"。
